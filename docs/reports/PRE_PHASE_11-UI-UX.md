# مستندات سیستم طراحی و بازطراحی تجربه کاربری (UI/UX)
## سامانه جامع مدیریت ایمنی، بهداشت و محیط زیست (HSE Guard)

**تاریخ تدوین:** ۲۶ اکتبر ۲۰۲۶  
**دامنه:** سیستم طراحی (Design System)، پوسته‌های روشن و تاریک، معماری ناوبری، کامپوننت‌های پایه و دسترس‌پذیری

---

## ۱. فلسفه طراحی و رویکرد بصری (Design Philosophy)

سامانه HSE Guard یک ابزار صنعتی و سازمانی با کاربری بحرانی است. اهداف اصلی در بازطراحی رابط و تجربه کاربری عبارتند از:
- **شفافیت اطلاعاتی در شرایط اضطراری:** هشدارهای سررسید گذشته، وضعیت‌های پرخطر و مجوزهای معلق باید بلافاصله با نشانه‌های رنگی و کنتراست بالا توجه کاربر را جلب کنند.
- **راست‌چین بومی و استاندارد (Persian RTL-First):** فاصله‌ها، جهت انیمیشن‌ها، نوار کناری و مسیرها به طور طبیعی و منطبق بر استاندارد فارسی و راست‌چین تنظیم شده‌اند.
- **پشتیبانی دوگانه پوسته (Light / Dark / System):** در محیط‌های پرنور صنعتی یا اتاق‌های کنترل تاریک، کاربر می‌تواند به آسانی بین پوسته‌های استاندارد جابه‌جا شود.
- **دسترسی‌پذیری سطح AA (WCAG 2.1):** حفظ نسبت کنتراست متن به پس‌زمینه (حداقل ۴.۵:۱)، برچسب‌های ARIA و هدایت کامل با صفحه‌کلید.

## ۲. توکن‌های طراحی (Design Tokens Architecture)

کلیه مقادیر بصری در قالب متغیرهای مدرن CSS در فایل `frontend/src/styles/global.css` تعریف شده‌اند:

### ۲.۱. پالت رنگ و توکن‌های پوسته

```css
/* پوسته روشن (Light Theme) */
:root, :root[data-theme="light"] {
  --bg-app: #f4f6f9;
  --bg-surface: #ffffff;
  --bg-subtle: #f8fafc;
  --border: #e2e8f0;
  --text-main: #0f172a;
  --text-muted: #64748b;
  --primary: #0284c7;
  --primary-hover: #0369a1;
  --primary-bg: #e0f2fe;
  --success: #16a34a;
  --warning: #d97706;
  --danger: #dc2626;
  --info: #2563eb;
}

/* پوسته تاریک (Dark Theme) */
:root[data-theme="dark"] {
  --bg-app: #0b0f19;
  --bg-surface: #131b2e;
  --bg-subtle: #1c2640;
  --border: #2a3756;
  --text-main: #f1f5f9;
  --text-muted: #94a3b8;
  --primary: #38bdf8;
  --primary-hover: #7dd3fc;
  --primary-bg: #0c4a6e;
  --success: #22c55e;
  --warning: #f59e0b;
  --danger: #ef4444;
  --info: #60a5fa;
}
```

### ۲.۲. سایه‌ها و عمق بصری (Elevation & Shadows)
- `--shadow-sm`: سایه ملایم برای کارت‌های داده (`0 1px 2px rgba(0, 0, 0, 0.05)`)
- `--shadow-md`: سایه استاندارد برای کارت‌های اصلی و هدر (`0 4px 6px -1px rgba(0, 0, 0, 0.07)`)
- `--shadow-lg`: سایه برجسته برای منوهای بازشونده و دیالوگ‌های مدال (`0 10px 15px -3px rgba(0, 0, 0, 0.1)`)
- `--shadow-xl`: سایه مدال‌های تمام‌صفحه و لایه‌های رویی (`0 20px 25px -5px rgba(0, 0, 0, 0.2)`)

### ۲.۳. شعاع گوشه‌ها (Border Radius)
- `--radius-sm`: `6px` (برای بج‌ها و تگ‌ها)
- `--radius-md`: `10px` (برای دکمه‌ها و فیلدهای ورودی)
- `--radius-lg`: `16px` (برای کارت‌ها و جداول)
- `--radius-xl`: `24px` (برای دیالوگ‌ها و مدال‌ها)

## ۳. موتور تغییر پوسته (Theme Engine)

موتور پوسته در کامپوننت `ThemeContext.tsx` پیاده‌سازی شده و از سه وضعیت پشتیبانی می‌کند:
1. **روشن (`light`):** اعمال تم روشن با کنتراست بالا.
2. **تاریک (`dark`):** اعمال تم تاریک ارگونومیک برای شیفت‌های شب و اتاق‌های کنترل.
3. **سیستم (`system`):** شنود تغییرات تم سیستم‌عامل کاربر از طریق `window.matchMedia("(prefers-color-scheme: dark)")` و تطبیق خودکار آن.

وضعیت انتخابی کاربر در کلید `hse_theme` در `localStorage` ذخیره می‌شود تا در دفعات بعدی مراجعه، بدون پرش (Flicker) بارگذاری شود.

## ۴. معماری ناوبری و ساختار بدنه (Navigation & Layout Shell)

### ۴.۱. نوار کناری دسته‌بندی‌شده (Sidebar)
ماژول‌های دوازده‌گانه در ۵ دسته عملیاتی گروه‌بندی شده‌اند:
1. **اصلی:** داشبورد مدیریتی، نمای یکپارچه
2. **عملیات میدانی:** مجوزهای کار (PTW)، بازرسی‌ها و اقدامات، حوادث و شبه‌حوادث
3. **سرمایه و منابع:** کارکنان و صلاحیت و PPE، تجهیزات صنعتی و کالیبراسیون، ارزیابی ریسک‌ها
4. **دانش و هوش مصنوعی:** پایگاه دانش قوانین، دستیار هوشمند HSE
5. **نظارت و مدیریت:** گزارش‌های تحلیلی، مرکز اعلان‌ها، گزارش حسابرسی امنیتی

ویژگی‌ها:
- قابلیت جمع شدن در دسکتاپ (Collapsible) برای افزایش فضای نمایش جداول پرستون.
- منوی کشویی در دستگاه‌های تلفن همراه و تبلت با لایه پوششی تیره (Backdrop).

### ۴.۲. هدر سامانه (Topbar / Header)
- نمایش عنوان سامانه و مسیر راهنما (Breadcrumbs).
- سوئیچر سریع پوسته با آیکون‌های استاندارد.
- زنگوله اعلان‌ها به همراه نشانگر تعداد اعلان‌های خوانده‌نشده.
- نماد پروفایل کاربری با نشانگر نقش (مدیر ارشد / کاربر استاندارد).

## ۶. دسترس‌پذیری و استانداردهای رابط کاربری (Accessibility / a11y)

1. **مدیریت فوکوس (Focus Rings):** کلیه المان‌های تعاملی دارای حلقه فوکوس مشخص با رنگ متمایز (`outline: 2px solid var(--primary)`) هستند.
2. **ناوبری با صفحه‌کلید (Keyboard Navigation):** منوها و مدال‌ها کاملاً با کلیدهای Tab، Enter و Escape قابل کنترل هستند.
3. **سازگاری با صفحه‌خوان‌ها:** کلیه دکمه‌های آیکونی دارای صفات `aria-label` مناسب فارسی هستند.
4. **کنتراست استاندارد:** نسبت کنتراست رنگ‌های متن نسبت به پس‌زمینه در هر دو پوسته در سطح بالای استانداردهای WCAG 2.1 قرار دارد.
